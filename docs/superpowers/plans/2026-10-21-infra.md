# Plano: Infraestrutura AWS (Task 2, agente 1)

Branch `fase1/infra`. Escopo: `infra/**` e `.github/workflows/infra.yml`. CDK v2 (TypeScript), jest + ts-jest com `aws-cdk-lib/assertions`.

## Arquitetura
- `lib/config.ts`: configuracao tipada por ambiente (dev/prod): classes de instancia, NAT (dev 1, prod 2), retencao, orcamento (dev 100 USD).
- `lib/volti-app.ts`: fabrica `createVoltiApp()` que monta todas as stacks e aplica tags `projeto=volti`/`ambiente`; usada por `bin/volti.ts` e pelos testes.
- Stacks (sa-east-1, `env` fixo, sem lookups): `NetworkStack`, `DataStack`, `AuthStack`, `MessagingStack`, `IotStack`, `ApiStack`, `WafStack` (us-east-1, exigencia do CloudFront), `AdminWebStack`, `ObservabilityStack`.
- Parametros SSM em `/volti/<env>/...` (lista fixa no brief); README documenta o mapeamento para as variaveis do `.env.example`.
- Certificado ACM importado por contexto `certificateArn` (default ficticio para synth); imagem da API via ECR + contexto `apiImageTag`.
