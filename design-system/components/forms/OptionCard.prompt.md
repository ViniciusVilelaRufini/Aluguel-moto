Radio-style card for choosing one option from a short list (plano, seguro, pagamento).
```jsx
<OptionCard title="Por minuto" description="Ideal para trajetos curtos" price="R$ 0,79" priceNote="/min" selected onClick={…} />
<OptionCard title="Seguro básico" badge="Obrigatório" price="R$ 1,50" />
```
Selected = green-soft fill + green border. Stack with 10px gap.
