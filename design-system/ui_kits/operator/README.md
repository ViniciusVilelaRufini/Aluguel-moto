# Volti — App do operador de campo

Perfil para a equipe que mantém a frota. Reaproveita `../app/ios-frame.jsx` e `../app/MapView.jsx`.

- `TaskList.jsx` — header escuro (diferencia do app do cliente), resumo do turno, tarefas: trocar bateria, recolher, manutenção, reposicionar
- `TaskDetail.jsx` — mapa da moto, "Destravar em modo serviço" (sem cobrança), registro da bateria por nº de série, checklist (freio, pneus, luzes, campainha, limitador) e foto obrigatória
