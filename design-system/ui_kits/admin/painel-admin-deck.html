10 · Por trás do painel

Como funciona um bloqueio remoto

O painel nunca fala direto com a moto: todo comando passa pela API, que grava a auditoria e envia o estado desejado ao rastreador.

1
O admin clica em "bloquear"
A API registra a ação no log de auditoria.
2
Estado desejado
A API atualiza o device shadow no AWS IoT Core.
3
Rastreador recebe por MQTT
Com a moto andando, reduz a potência e só trava abaixo de ~3 km/h.
4
Confirmação
O rastreador confirma; uma regra do IoT Core avisa a API.
5
Painel atualizado
A API atualiza o Redis e o painel mostra a moto bloqueada em tempo real.
6
Sem sinal?
O comando fica pendente no shadow e é aplicado quando a moto reconectar.
