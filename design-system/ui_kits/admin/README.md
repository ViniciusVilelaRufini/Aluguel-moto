# Volti — Painel web do admin

Desktop (1440×900). SideNav escura + header com busca.

- `FleetView.jsx` — mapa ao vivo com filtros por status (`FleetStatus`), ficha da moto, comandos remotos (bloquear, desbloquear, buzina, limitar velocidade, modo roubada), replay e log de auditoria
- `AlertsView.jsx` — queda, movimento sem aluguel, rastreador desconectado, bateria crítica, aluguel longo, parada fora do ponto
- `ZonesView.jsx` — área de operação, pontos de devolução, zona proibida e velocidade reduzida + regras automáticas
- `FinanceView.jsx` — KPIs, receita diária, receita por plano, cauções e repasses
- Clientes, Operação e Preços aparecem na navegação mas estão em branco de propósito.
